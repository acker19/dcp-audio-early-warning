What it does

Sense, detect, notify — one ESP32 node per machine.

Sense

An acoustic and vibration sensor on each machine listens continuously, on-device, without needing a constant connection to the cloud.

Detect

A lightweight autoencoder flags deviations from that specific machine's own normal — not a generic average across every machine on site.

Notify

A confirmed anomaly is logged, shown live on the dashboard, and routed to whoever is responsible for that machine.
